# Описание папки data

В этой папке хранятся данные, на основе которых будет показана актуальность проекта

## Какие файлы здесь находятся

- `dataJLI.sav` — исходный файл с данными, взят из открытого источника: https://data.mendeley.com/datasets/dy8ycy7rby/2
- `dataset.csv` — те же данные в формате CSV, который удобно использовать в Python.
- `metadata.txt` — описание столбцов и расшифровка некоторых числовых значений.
- `README.md` — описание файлов, которые находятся в этой папке.

## Общая информация о данных

Данные содержат информацию о студентах, их опыте управления временем и повседневной активности. В них отражено, сколько задач студенты планируют и выполняют, сколько времени уделяют самостоятельной учёбе и внеучебным занятиям, а также как оценивают свою продуктивность. 

## Описание столбцов

- `grade` — этап исследования: первый, второй или третий.
- `major` — направление обучения участника.
- `gender` — пол участника.
- `age` — возраст участника.
- `TME` (Time Management Experience) — опыт управления временем.
- `DOR` (Days of Recording) — количество дней, в течение которых велись записи.
- `TP` (Total Planned) — общее количество запланированных задач.
- `TC` (Total Completed) — общее количество выполненных задач.
- `ccc` (Completed Category Count) — количество категорий, в которых были выполнены задачи.
- `PCR` (Planned Completion Rate) — доля выполненных запланированных задач.
- `DIL` (Daily Independent Learning Time) — время самостоятельного обучения за день, в минутах.
- `DET` (Daily Extracurricular Time) — время на внеучебную деятельность за день, в минутах.
- `DSE` (Daily Self-Evaluation Scores) — ежедневная самооценка.

Некоторые значения в таблице записаны числами, которые соответствуют определённым вариантам ответов. Их расшифровка хранится в файле `metadata.txt`.
